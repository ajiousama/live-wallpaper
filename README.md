# live-wallpaper

松山のライブ壁紙を、会社PCに重い取得処理をさせずに表示するための専用リポジトリです。

## 構成

- GitHub Actions: 5分ごとにデータ取得・整形
- GitHub Pages: 壁紙本体と生成済みJSONを配信
- 表示PC: Pagesを表示し、軽量JSONだけを定期読込
- Gitへの定期コミット: なし

## 現在の受け皿

- JR松山駅
- JR市坪駅
- 松山空港
- 空港バス
- 高速・中距離バス
- フェリー

現時点ではデータ取得アダプターは未接続です。各公式ソースの取得処理は `scripts/` に追加し、`data/` のJSONへ統一して出力します。

## 更新間隔

Actionsは5分間隔で起動する設定です。GitHubのスケジュール実行は混雑時に多少遅れる場合があります。
